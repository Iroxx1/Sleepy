# Über Sleepy

**Kurzbeschreibung (GitHub „About“):**

> Self-hosted CPAP/PAP-Datenanalyse für ResMed-SD-Karten – lokal auf Proxmox/Debian, ohne Cloud. Import per ZIP, synchronisierte Flow-/Druck-/Leck-Diagramme, Ereignisse, Trends, Hardware-Verwaltung und Berichte.

**Topics:** `cpap` `sleep-apnea` `resmed` `airsense` `edf` `self-hosted` `proxmox` `fastapi` `react` `echarts` `health-data` `privacy`

Sleepy ist ein privates „Self-hosted SleepHQ“: Die SD-Karte des PAP-Geräts wird als ZIP hochgeladen, alle Originaldateien werden unverändert und prüfsummengesichert archiviert, die Daten werden normalisiert und Nacht für Nacht bis auf den hochaufgelösten Atemfluss analysierbar gemacht. Alle Daten bleiben auf dem eigenen Server – keine Cloud, keine Telemetrie, keine externen Skripte oder Schriften.

Sleepy ist ein Analyse- und Visualisierungswerkzeug und **kein Medizinprodukt**. Die dargestellten Informationen dienen ausschließlich der technischen Analyse der PAP-Therapiedaten und ersetzen keine ärztliche Beratung.
